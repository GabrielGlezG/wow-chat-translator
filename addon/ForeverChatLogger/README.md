# ForeverChatLogger (WoW Chat Translator Addon)

Addon ligero para World of Warcraft (compatible con **WoW Forever**, servidores **WotLK 3.3.5a**, Classic y Retail).

---

## 🇪🇸 Español

### ¿Qué hace este Addon?
World of Warcraft almacena el chat en memoria y tarda minutos en escribirlo a disco. **ForeverChatLogger** activa `/chatlog` y vacía los mensajes a disco **0.20s** después de cada evento en Grupo, Banda, Susurro o Hermandad.

> ⚠️ **Nota:** Este addon requiere la aplicación de escritorio gratuita para traducir los mensajes en tiempo real:  
> 👉 **[Descargar WoW Chat Translator en GitHub](https://github.com/GabrielGlezG/wow-chat-translator/releases)**

### Comandos en el juego
* `/translator` — Muestra el estado del logger.
* `/translator flush` — Vaciado manual de prueba a disco.
* `/translator on / off` — Activa o desactiva el logging.

---

## 🇬🇧 English

### What does this Addon do?
WoW buffers chat logs to disk. This addon maintains `/chatlog ON` and debounces a flush to disk **0.20s** after incoming chat events.

> ⚠️ **Note:** Requires the free companion desktop app for real-time translation:  
> 👉 **[Download WoW Chat Translator on GitHub](https://github.com/GabrielGlezG/wow-chat-translator/releases)**
